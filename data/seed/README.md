# Seed Data

Seed store, shelf, product, inventory, promotion, and demo-state fixtures.

## `demo-store.json`: the store `/demo` shows

The FE demo store (`apps/web/src/fixtures/demo/store.ts`): `store-001`, `v1`, 555 products (P001, the named catalog P002–P020 without P017/P019, and filler stock P101 onward). It is generated by `cd apps/web && npm run seed:export`; do not edit it by hand, and a web test fails if it drifts from the FE.

Its shape is apps/api's store fixture (`FixtureFile` in `apps/api/retailtwin_api/schemas.py`). To serve it from the API:

```bash
cd apps/api
STORE_FIXTURE_PATH=../../data/seed/demo-store.json LIVE_TWIN_BACKEND=memory python -m retailtwin_api
```

Notes for the BE:

- P017 is not in it on purpose (the demand-surge scenario adds it). The flagship reset (`flagship/controller.py`, `_reseed_twin`) re-reads `DEFAULT_FIXTURE`, not `STORE_FIXTURE_PATH`, and puts P017 on `A02-S03`, which this store gives to filler `P157`.
- Slots follow the FE layout (`A01-S20`, `GDC01-S07`, ...), not `demo_seed.py`'s `DEMO_PRODUCTS` (`A01-S01`, ...). Only P001 is the same in both.
- Product names, prices, anomalies, revenue, promotions and checkouts are not in it: the store fixture has no fields for them.
